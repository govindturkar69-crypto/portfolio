## Run locally

### Requirements

- Node.js 22.13 or newer
- pnpm

### Setup

```bash
git clone https://github.com/govindturkar69-crypto/portfolio.git
cd portfolio
pnpm install
pnpm dev
```

Open the local URL printed in the terminal.

### Quality checks

```bash
pnpm lint
pnpm build
```
